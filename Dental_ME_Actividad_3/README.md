# Dental M&E — Actividad Colaborativa #3

Sitio HTML5 + CSS3 + JavaScript. Tres páginas: Inicio, Servicios y Equipo.

## Funcionalidades con JavaScript (`js/script.js`)
- **Validación del formulario de solicitud de cita** (index.html): campos de nombre, correo, fecha, tipo de servicio y mensaje; eventos `submit`, `blur`, `input` y `change`; errores por campo, fecha mínima de hoy y contador de caracteres.
- **Filtro de servicios** (servicios.html): evento `click` sobre botones que muestran u ocultan tarjetas según su categoría (`data-categoria`).
